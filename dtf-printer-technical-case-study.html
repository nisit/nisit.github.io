Technical Architecture: Direct-to-Film (DTF) Express

Project Scope: Scalable Industrial Print E-Commerce Portal
Performance: 7-Digit Annual Revenue Support | 0% Downtime

Architecture Overview: A highly decoupled WordPress/WooCommerce implementation using a custom dtf_booking product type. The system utilizes a reactive frontend (JSX) and a robust PHP backend driven by modern Design Patterns to ensure maintainability and high-speed execution.

1. Design Patterns & OOP Implementation

To support rapid scaling and feature expansion, the following patterns were implemented:

Strategy Pattern
Used for dynamic pricing. The system hot-swaps calculation logic (Fixed, Variable, or Length-based) at runtime based on product metadata.
Dependency Injection & Container
Decouples services (Image processing, Cart logic, Shipping sync) and utilizes lazy loading to maintain a low memory footprint.
Singleton & Registry
Ensures global state consistency for critical settings and shared database connections across custom tables.
Zero-Trust Pricing Model
Cross-layer validation. Frontend provides UI feedback, while the Backend re-executes the entire logic from raw data upon add_to_cart.

2. Advanced Logic: The "Simulated Cart" Order Modification

One of the system's most complex features is the Post-Purchase Order Modification. This allows users to pause a live production order and edit items without a full cancellation/refund cycle.

  • Simulation Layer: When an order is edited, the system hydrates a "Simulated Cart" with existing order items, applied discounts, and shipping fees.
  • Wallet Adjustment Logic: Variations in price (due to quantity or size changes) are calculated as a Wallet Adjustment Fee. The system handles negative adjustments and tax-inclusive recalculations in real-time.
  • Production Sync: Orders are paused/resumed via Supabase integration, ensuring the printing "gang-sheet" queue is updated instantly to prevent waste.

3. Data Integrity & Infrastructure

Custom Schema Design

To offload heavy metadata and history from the standard WP tables, the system uses specialized tables for:

  • Creative Management: User/Order creative tracking for instant re-ordering.
  • Shipment Intelligence: Status history tracking (DHL/UPS) for predictive delivery timeline modeling.
  • Financial Audit: Storage of original totals and tax for post-order adjustments.

Automated Lifecycle Management

The system maintains a clean production environment via scheduled CRON jobs:

  • Storage Optimization: Automated purging of high-resolution production files (multi-GB) after a set retention period, balancing server load and order history needs.
  • Sync Engine: 30-day lookback on completed orders to sync actual delivery data with Shiptastic and DHL, building a historical dataset for shipping performance.

4. Performance & Reliability

  • Uptime: The platform has seen zero downtime over a 24-month period despite rapid 7-digit revenue growth.
  • Security: All calculations are server-side "Source of Truth," preventing client-side injection of pricing or discount data.
  • Scalability: Modular Add-On architecture (Gamification, Role-based Discounting) allows for feature expansion without touching core booking logic.
