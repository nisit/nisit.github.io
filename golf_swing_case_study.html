The Challenge

Understanding Golf Swing Analysis

Golf swing analysis relies on measuring the torque applied through the club during a swing. The "Groove Number" quantifies how consistently a golfer can replicate their ideal swing pattern. A lower groove number indicates better consistency and typically correlates with better performance.

The Problem with Our Original Algorithm

Our initial implementation used Butterworth filtering — a frequency-domain filtering technique. While this provided good noise reduction, we discovered it was fundamentally flawed for our use case.

💡 Critical Insight

The impact phase — the most critical moment in the swing — is a transient signal: a short-duration, high-amplitude event lasting less than 1 millisecond. This is fundamentally different from the smooth, continuous signals in the rest of the swing.

Why Frequency-Domain Filtering Falls Short

Frequency-domain filtering (like Butterworth) works by:

  1. Converting the time-domain signal to frequency domain (Fourier Transform)
  2. Attenuating high-frequency components
  3. Converting back to time domain (Inverse Fourier Transform)

The Problem: Transient events (like impact) contain energy across a wide range of frequencies, including high frequencies. When we filter out these high frequencies to reduce noise, we inadvertently distort the transient — smoothing out the very peak we're trying to measure.

The impact signature gets "smeared" across time, reducing peak amplitude and spreading energy into adjacent time windows.

The Solution: Time-Domain Filtering

Mathematical Foundation

The key insight came from understanding how different filtering approaches handle transient signals. Rather than transforming to frequency domain and back, we can apply smoothing directly in the time domain to preserve local features.

Savitzky-Golay Filter: How It Works

The Savitzky-Golay filter works by fitting a polynomial to a local window of data points, then using that polynomial to compute the smoothed value at the center point.

For each point i, fit polynomial: y = a₀ + a₁x + a₂x² + ... + aₖxᵏ
over window [i-n, i+n], where n = (window-1)/2

Key Parameters Used

  • Window Size: 15 samples (~150ms at 100 Hz)
  • Polynomial Order: 3 (cubic fit)
  • Rationale: Balances smoothing with feature preservation

🔑 Why This Works

The polynomial fitting happens locally in time, so high-frequency noise is smoothed out, but sharp transients (like impact) are preserved because they dominate the local data. The filter "sees" the impact peak and fits a polynomial that respects it.

Additional Improvements

1. Unfiltered Ideal Curve

We stopped filtering the "ideal torque" reference curve. This preserves the transient characteristics in the ideal pattern, allowing for more accurate comparison with the actual swing.

2. New Validation Metrics

To independently validate our improvements, we added three new time-domain metrics:

  • Impact Acceleration: Direct measurement of peak acceleration in a 75ms window around impact (50ms before, 25ms after)
  • Confidence Score: Signal consistency measure based on variance in pre-impact angular velocity (lower variance = more consistent)
  • Transient Energy Ratio: Proportion of energy in the impact transient versus total signal energy

1. Adaptive Window Sizing

Currently using fixed window size (15 samples). Consider adaptive windowing based on:

  • Local signal characteristics (noise level, rate of change)
  • Swing phase (smaller window near impact, larger during smooth phases)
  • Player skill level (pro vs amateur may need different parameters)
def adaptive_savgol_filter(data, base_window=15, polyorder=3):
    """Adjust window size based on local signal properties"""
    window_sizes = []
    for i in range(len(data)):
        # Calculate local variance
        local_var = np.var(data[max(0,i-10):min(len(data),i+10)])
        
        # Smaller window for low variance (smooth regions)
        # Larger window for high variance (noisy regions)
        window = int(base_window * (1 + local_var))
        window = window if window % 2 == 1 else window + 1  # Must be odd
        window_sizes.append(window)
    
    # Apply variable window filter
    return variable_savgol_filter(data, window_sizes, polyorder)

2. Wavelet-Based Analysis

Wavelets provide multi-resolution analysis — good for signals with both smooth and transient components:

  • Use wavelet transform to separate scales
  • Denoise smooth components, preserve transients
  • Reconstruct for improved signal-to-noise ratio
import pywt

def wavelet_denoise(data, wavelet='db4', level=3):
    """Wavelet-based denoising preserving transients"""
    # Decompose signal
    coeffs = pywt.wavedec(data, wavelet, level=level)
    
    # Threshold detail coefficients (noise)
    # Keep approximation (smooth) and large details (transients)
    threshold = np.std(coeffs[-1]) * np.sqrt(2 * np.log(len(data)))
    
    coeffs_thresh = [coeffs[0]]  # Keep approximation
    for detail in coeffs[1:]:
        # Soft threshold: shrink small coefficients, keep large ones
        detail_thresh = pywt.threshold(detail, threshold, mode='soft')
        coeffs_thresh.append(detail_thresh)
    
    # Reconstruct
    return pywt.waverec(coeffs_thresh, wavelet)

Core Principles Applied

  4. Systematic Comparison: Comparing algorithms on the same dataset with objective metrics proved the value of the changes.
